### About Me

- 🚀 **Specialization**: Designing resilient backend architectures, high-load microservices, and distributed cloud applications.
- 💼 **Focus**: Developing scalable **Open-Source Cloud ERP & CRM** systems engineered for real-time inventory, sales automation, and high-concurrency workloads.
- ⚡ **Server & DevOps**: Container orchestration with Docker & Kubernetes, Linux server tuning, reverse proxies (Nginx), and CI/CD pipelines.
- 🗄️ **Data & Caching**: Advanced relational modeling (PostgreSQL), distributed in-memory caching (Redis), and event streaming.
- 🤖 **AI & ML**: Integrating intelligent automation pipelines and LLM tooling into enterprise workflows.
